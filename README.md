# HR Employee Attrition Analysis

This repository contains a project analyzing employee attrition using a dataset from a corporate environment. The analysis is performed using a Jupyter Notebook, leveraging Python libraries such as pandas and numpy.

## Contents

- `WA_Fn-UseC_-HR-Employee-Attrition.csv`: The dataset containing employee information.
- `WA_Fn-UseC_-HR-Employee-Attrition.ipynb`: Jupyter Notebook with data analysis and preprocessing steps.

## Analysis Steps

1. **Data Loading**: Load the dataset into a pandas DataFrame.
2. **Data Preparation**: Set display options and explore the dataset.
3. **Data Transformation**: Convert categorical columns to numerical values.
4. **One-Hot Encoding**: Apply one-hot encoding to categorical columns.
5. **Mapping Boolean Values**: Map boolean values to integers.

## Usage

1. Clone the repository:
    ```sh
    git clone https://github.com/mobasir105/HR-Employee-Attrition.git
    ```
2. Navigate to the project directory:
    ```sh
    cd HR-Employee-Attrition
    ```
3. Open the Jupyter Notebook:
    ```sh
    jupyter notebook WA_Fn-UseC_-HR-Employee-Attrition.ipynb
    ```

## Dependencies

- pandas
- numpy
- Jupyter Notebook
